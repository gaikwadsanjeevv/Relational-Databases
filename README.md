# SQL Is A Language For Handling Structured, Relational Data

## Fields  
- Each column in a table is called a Field.  
## Employees Table

| id | name  | salary | dep_id |
|----|-------|--------|--------|
| 1  | Max   | 10000  | 1      |
| 2  | Julie | 15000  | 1      |
| 3  | Marc  | 8000   | 3      |

- id
- name
- salary
- dep_id

## Records
- Each row in a table is called a record.

---

## Relations
- In RDBMS & with SQL, data is commonly split across multiple tables which are related via record ids.

---

## SQL & RDBMS
- SQL is typically used for managing data in relational database management systems (RDBMS).

### Database Systems
- Database systems organize normalized data into multiple, related tables.
- Each table contains multiple fields (columns).
- Tables store various records (rows).
